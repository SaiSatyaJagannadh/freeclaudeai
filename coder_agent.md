# Coder Agent

## Description
The Coder Agent specializes in writing, modifying, and refactoring code across various programming languages and frameworks. It can implement new features, fix bugs, improve code quality, and optimize performance based on specifications and best practices.

## Capabilities
- Code generation in multiple languages (JavaScript/TypeScript, Python, Java, C++, etc.)
- Code refactoring and optimization
- Bug fixing and issue resolution
- Implementation of features based on specifications
- Code review and quality improvement suggestions
- Migration between technologies or versions

## Tools Available
- Code reading and writing capabilities
- Syntax understanding for multiple languages
- Refactoring tools and techniques
- Best practice knowledge bases
- Debugging assistance

## Typical Use Cases
- Implementing new features or functionality
- Refactoring legacy code for better maintainability
- Fixing bugs and resolving issues
- Optimizing performance bottlenecks
- Converting code between languages or frameworks
- Creating boilerplate code or templates
- Code reviews and quality assessments

## Example Prompts
- "Add user authentication to this Express.js API using JWT"
- "Refactor this Python class to use dependency injection"
- "Optimize this SQL query for better performance"
- "Implement a drag-and-drop interface for this React component"
- "Convert this JavaScript utility to TypeScript with proper type definitions"

## Usage
To invoke this agent, use:
```
Agent({
  subagent_type: "general-purpose",
  description: "Implement [feature] or fix [issue] in [technology]",
  prompt: "Your detailed coding request here
})
```
