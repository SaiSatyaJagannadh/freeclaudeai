## 🕹️ The games — zero install, just open the file

| Game | File | What it is |
|---|---|---|
| 🐍 **Nokia Snake** | [`index.html`](index.html) | The classic, in the style of the old Nokia phones |
| 🏏 **Nokia Cricket** | [`cricket.html`](cricket.html) | Retro cricket in the same pixel style |
| 🌴 **Vice City (basic)** | [`vice_city_game/vice_city_game.html`](vice_city_game/vice_city_game.html) | Top-down neon open-world: dodge cops & gangsters, grab cash/health/weapons, wanted-level system |

```bash
git clone https://github.com/SaiSatyaJagannadh/freeclaudeai.git
open freeclaudeai/index.html      # or double-click any .html file
```

Controls: **arrow keys / WASD**.

## 🤖 The agents

Six drop-in agent definitions for AI coding CLIs (Claude Code's Agent tool and similar):

| Agent | Role |
|---|---|
| [`researcher_agent.md`](researcher_agent.md) | Researches technologies and gathers context |
| [`coder_agent.md`](coder_agent.md) | Writes, modifies and refactors code |
| [`tester_agent.md`](tester_agent.md) | Writes tests and validates behaviour |
| [`debugger_agent.md`](debugger_agent.md) | Diagnoses bugs and proposes fixes |
| [`devops_agent.md`](devops_agent.md) | CI/CD, deployment and infrastructure |
| [`documentation_agent.md`](documentation_agent.md) | READMEs, docs and code comments |
